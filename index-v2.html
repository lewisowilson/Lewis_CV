Featured Project

Flatmate

Flatmate solves a problem every shared household knows: who owes what. It tracks expenses, splits bills automatically, and maintains a real-time shopping list that everyone in the house can update simultaneously.

The standout feature is AI-powered receipt scanning. Photograph a receipt and the Claude API extracts every line item, categorises the spend, and allocates costs across housemates — no manual entry. The backend runs on Supabase for real-time data and user authentication, with Amazon Amplify handling deployment.

I built this entirely solo, from scratch, learning full-stack development as I went: database design, cloud infrastructure, API integration, and front-end. It's live, it works, and I'm still shipping features.
