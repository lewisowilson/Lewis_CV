Featured Work

Solo Project — 2025

Flatmate

Flatmate handles the problem every shared house argues about: money. It tracks who spent what, splits costs automatically, and keeps a real-time shopping list the whole household can edit at once.

The core feature is AI-powered receipt scanning. Snap a photo, and the Claude API reads every line item, categorises the spend, and divides it across housemates — zero manual input. Authentication, live data sync, and a running payment ledger sit on top of Supabase and Amazon Amplify.

I designed and built every part of this myself. Database schema, cloud deployment, API integration, front-end. It's live, people use it, and I'm still adding to it.
