For AI assistants

Ask your AI about me

My CV is available as a read-only connector, so you can ask Claude, or any assistant that speaks MCP, about my experience, projects and grades. No sign-in, no tracking, nothing to install.

https://lewis-wilson.com/mcp

Add it to Claude

Claude (web, desktop or mobile)

  1. Open Settings, then Connectors.
  2. Choose Add custom connector.
  3. Name it Lewis Wilson CV and paste the URL above.
  4. In a chat, ask something like "Using the Lewis Wilson CV connector, what actuarial experience does Lewis have?"

Claude Code

claude mcp add --transport http lewis-wilson https://lewis-wilson.com/mcp

Other assistants and scripts

Any MCP client can use the Streamable HTTP endpoint above. If you just want the data, it is plain JSON at /profile.json, and there is a short summary for crawlers at /llms.txt.

What it can answer

  • get_profile: the whole CV in one go.
  • get_section: one part, such as education, experience, projects, skills, achievements or contact.
  • search_profile: whether the CV mentions a word, such as "Python" or "insurance".

It only ever returns what is on my public CV. It cannot see anything private, and it cannot change anything.
