Football Scouting Model

Using data to find players who fit.

Watching Brentford’s recruitment approach helped spark this project: how could a club use data to identify promising players within its budget?

I designed a SQL database and built a model that scores and ranks players using match and performance data, producing recruitment shortlists against positional and budget constraints.

The model uses per-90-minute metrics and a minimum playing-time threshold to reduce the influence of small samples. I’m now exploring which metrics matter most for each position, how to weight them and how to compare players across leagues.

Skills: SQL · Data modelling · Statistical thinking · Football analysis

Flatmate

Making shared household expenses easier to manage.

A full-stack prototype for tracking household costs and automatically splitting bills between flatmates.

It combines AI-powered receipt scanning through the Claude API, a real-time shared shopping list, user authentication and a ledger showing who owes what. I built it using Supabase and AWS Amplify.

The project brings together a practical everyday problem, interface design and the technical work needed to connect everything.

Skills: Full-stack development · API integration · Authentication · Database design

Sky Viewer

Helping you work out what to look for in tonight’s sky.

I came up with the concept together with my grandad.

An interactive star map that shows the sky from your location at any date and time, with constellations and objects labelled.

It recommends targets for the night based on how high they are, how dark the sky is, your equipment and the cloud forecast. Each object explains where to look, the best time to see it and whether you need binoculars or a telescope.

Skills: Web development · Data visualisation · API integration · Interface design
